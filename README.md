# sudoku-backtracking

A Sudoku solver using backtracking, in plain Python.

## Layout
- `runner.py` — entry point.
- `classes.py` — board/cell model.
- `solver_functions.py` — the backtracking search.
- `var_handlers.py` — helpers for candidates/constraints.
- `visuals.py` — board display.

## Run
`python runner.py`
